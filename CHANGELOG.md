# Changelog

## 0.2.0 - 2026-06-07

- Added structured input validation with warnings and errors.
- Added CLI validation mode with `--validate-only` and `--strict`.
- Added review dashboard metrics to generated reports.
- Added prioritized action register generation with a configurable variance
  threshold.
- Added machine-readable JSON project summaries for automation.
- Added input schema documentation and a second synthetic example project.

## 0.1.0 - 2026-06-07

- Added the initial Python CLI for generating construction management report
  drafts from structured JSON input.
- Added synthetic example data for cost review, meeting notes, and technical
  material tracking.
- Added tests, project metadata, documentation, and CI configuration.
- Added release readiness files: issue templates, pull request template,
  security policy, and release checklist.
