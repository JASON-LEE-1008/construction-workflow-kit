# Security Policy

## Supported versions

This project is early-stage. Security fixes are currently handled for the latest
commit on the `main` branch and for the latest tagged release, if a release tag
exists.

## Reporting a vulnerability

Do not open a public issue for a vulnerability or for confidential construction
project data exposure.

Use GitHub's private vulnerability reporting feature if it is available for this
repository. If it is not available, open a minimal public issue that says a
private security report is needed, without including exploit details or private
data.

## Data safety scope

Reports and contributions must not include real client names, private company
names, internal project names, personal contact details, live contract values,
or confidential technical material.

## Maintainer response

The maintainer will review reports, remove exposed sensitive data when possible,
and prepare a fix or documentation update before public disclosure.
